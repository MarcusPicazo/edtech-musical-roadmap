# EdTech Musical - Strategic Roadmap 🎵

An interactive, hyper-scalable presentation detailing the business roadmap for an EdTech Music startup in Spain. Designed to outline the transition from a traditional SMB model to a tech-driven exponential growth model funded via crowdfunding.

### 🚀 Technical Overview
This project is a decoupled front-end application built with high performance and visual storytelling in mind. It eschews heavy libraries in favor of native Web APIs for smooth animations.

* **HTML5 & Semantic Structure:** Clean layout with clear separation of concerns.
* **Tailwind CSS (via CDN):** Rapid, utility-first styling for a sleek, dark-mode-centric aesthetic.
* **Vanilla JavaScript:** * `Intersection Observer API`: Used for performant scroll-triggered fade animations and progress bar fill logic.
  * `Canvas API`: Implements a highly optimized, organic wobbly path that renders a glowing trail reacting dynamically to the user's scroll depth (`requestAnimationFrame`).

### 📦 Quick Start
1. Clone the repository.
2. Install dependencies: `npm install`
3. Run the local server: `npm start`

# EdTech Musical - Roadmap Estratégico 🎵

Una presentación interactiva e hiper-escalable que detalla la hoja de ruta comercial de una startup EdTech Musical en España. Diseñado para perfilar la transición de un modelo tradicional de pyme a un modelo de crecimiento exponencial impulsado por tecnología y financiado mediante micromecenazgo.

### 🚀 Resumen Técnico
Este proyecto es una aplicación front-end desacoplada, construida pensando en el alto rendimiento y la narrativa visual. Evita librerías pesadas en favor de las API nativas de la web para animaciones fluidas.

* **HTML5 y Estructura Semántica:** Diseño limpio con una clara separación de responsabilidades.
* **Tailwind CSS (vía CDN):** Estilos de utilidad para una estética moderna y centrada en el "dark mode".
* **Vanilla JavaScript:** * `Intersection Observer API`: Utilizado para animaciones de entrada eficientes y lógica de llenado de barras de progreso al hacer scroll.
  * `Canvas API`: Implementa un camino orgánico y altamente optimizado que dibuja una estela brillante, reaccionando dinámicamente a la profundidad del scroll del usuario (`requestAnimationFrame`).

### 📦 Inicio Rápido
1. Clona el repositorio.
2. Instala las dependencias: `npm install`
3. Ejecuta el servidor local: `npm start`
