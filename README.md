## 🇬🇧 English

An interactive, web-based roadmap developed for **Nimio** to outline the strategic vision and developmental milestones of their musical EdTech platform[cite: 5]. This project provides a clear, visual, and engaging interface to track progress, feature rollouts, and future implementations.

As a **Systems Engineer & AI Product Engineer**, I designed this architecture to be lightweight, modular, and highly responsive, ensuring that stakeholders and team members can easily navigate the project's lifecycle.

### 🔗 Live Link
Access the interactive roadmap here: [https://marcuspicazo.github.io/edtech-musical-roadmap/](https://marcuspicazo.github.io/edtech-musical-roadmap/)

### Technologies & Technical Skills
* **Core Logic:** Vanilla JavaScript (ES6+) for dynamic milestone rendering and DOM manipulation[cite: 5].
* **UI/UX & Styling:** HTML5 semantic structure and CSS3 paired with Tailwind CSS for a clean, modern, utility-first design[cite: 5].
* **Architecture:** Component-based approach without heavy external frameworks, ensuring optimal load times and easy maintainability.

### How to Run Locally
1. Clone the repository.
2. Run `npm install` to load the local development dependencies[cite: 5].
3. Run `npm start` to serve the project locally.

## 🇪🇸 Español

Un *roadmap* interactivo basado en la web, desarrollado para **Nimio** con el objetivo de esbozar la visión estratégica y los hitos de desarrollo de su plataforma EdTech musical[cite: 5]. Este proyecto proporciona una interfaz clara, visual y atractiva para realizar un seguimiento del progreso, el lanzamiento de nuevas características y las futuras implementaciones.

Como **Systems Engineer & AI Product Engineer**, diseñé esta arquitectura para ser ligera, modular y altamente responsiva, asegurando que las partes interesadas y los miembros del equipo puedan navegar fácilmente por el ciclo de vida del proyecto.

### 🔗 Enlace a la plataforma
Puedes explorar el roadmap interactivo aquí: [https://marcuspicazo.github.io/edtech-musical-roadmap/](https://marcuspicazo.github.io/edtech-musical-roadmap/)

### Tecnologías y Habilidades Técnicas
* **Lógica Central:** Vanilla JavaScript (ES6+) para el renderizado dinámico de hitos y la manipulación del DOM[cite: 5].
* **UI/UX y Estilos:** Estructura semántica en HTML5 y CSS3[cite: 5], junto con Tailwind CSS para un diseño limpio, moderno y basado en utilidades.
* **Arquitectura:** Enfoque modular sin frameworks externos pesados, garantizando tiempos de carga óptimos y un mantenimiento sencillo.

### Cómo Ejecutarlo Localmente
1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias locales[cite: 5].
3. Ejecuta `npm start` para levantar el proyecto de forma local.
